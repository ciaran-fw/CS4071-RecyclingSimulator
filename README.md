# CS4071 - Project - VR Recycling Simulator

A VR recycling game developed in Unity for Meta Quest 2 and 3. You have to pick up rubbish from a conveyor belt and sort it into recycling bins to achieve a high score.

## Features

- Can grab and throw objects.
- Different rubbish categories.
- Scoring and timer.
- Random weighted rubbish spawning.
- In-game interactable UI.
- Best score persistant tracking.

## Using

- Unity 6.3 LTS
- C#
- XR Interaction Toolkit
- OpenXR

## Project Scripts

- "Assets/Project/Scripts" - Gameplay scripts.
- "Assets/Project/Editor" - Tool script.
